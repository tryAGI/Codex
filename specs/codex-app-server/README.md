# Codex App Server protocol snapshots

Each directory holds `codex_app_server_protocol.schemas.json` as generated by the Codex CLI:

```bash
codex app-server generate-json-schema --experimental --out specs/codex-app-server/<version>
```

| Version | Used by |
|---------|---------|
| `0.162.1` | Test fixture: `CodexThreadRpc` responses are validated against its required fields. |
| `0.165.0` | Reference for `CodexAppServerClient` and the samples. |

Snapshots are immutable; add a new directory for a new version. The schemas are generated from
OpenAI Codex, which is licensed under Apache-2.0.
